# Security

AURA Switcher sees what you type, so security reports matter.

Please report vulnerabilities **privately** by email: auraswitcher@gmail.com (not in a public issue). Include the version, OS and steps to reproduce. Please don't include real passwords or personal text.

Supported: the latest release (see the [releases](https://github.com/klbk/aura-switcher/releases)). We'll reply as soon as we can and credit you in the fix if you wish.
